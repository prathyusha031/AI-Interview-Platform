# AI Interview Preparation Platform

An AI-powered interview preparation platform built using React, JavaScript, and Gemini AI. The application helps students and job seekers practice technical and HR interviews by generating AI-driven interview questions in real time.

## Features

* AI-generated interview questions using Gemini AI
* Technical interview preparation (Python, Java, Data Science)
* HR interview practice
* Interactive and user-friendly interface
* Fast and responsive React application
* Secure API key management using environment variables

## Tech Stack

* React.js
* JavaScript
* Vite
* Gemini AI API
* HTML5
* CSS3
